# App icon

`AppIcon.png` was generated with the built-in imagegen tool. Its palette takes
cues from the [uinaf design system](https://github.com/uinaf/design): near-black,
off-white, and phosphor lime. The build script creates the macOS icon sizes and
ICNS from this source image.

## Generation prompt

Use case: logo-brand. Asset type: production macOS app icon for Quiet Control, a simple Bose QC35 II Bluetooth manager. Generate a single 1024x1024 square icon. Style inspired by uinaf: near-black #0a0a0a, restrained technical geometry, one phosphor-lime accent, plenty of negative space. Center a bold minimal over-ear headphone silhouette in warm off-white, with one small phosphor-lime rectangular indicator in the right earcup. Flat precise graphic, even strokes, immediately legible at 32px. Dark rounded-square macOS tile inset slightly from the image bounds, transparent outside the tile, subtle hairline edge. No lettering, no Bose logo, no wordmark, no gradients, no glow, no 3D, no ornamental circuitry. Deliver only the icon artwork, not a mockup or presentation sheet.
